# 💎 N8 Command Deck — Mobile 📱

The pocket twin of Nathan's Windows **N8 Command Deck**: every app, one tap away, on the phone.

**Live:** https://qamotech.github.io/n8cd/

- 🗂️ All **83 tiles** from the desktop deck — GitHub Pages apps, the DevDashboard fleet, repos, shop + quick links
- ⭐ Favorites, 🕘 Recents, ➕ custom tiles, 📋 copy link, 📤 share, 💾 deck-data export/import — saved on the phone
- 🌦️ Baltimore weather strip in the top bar — now + full 7-day stats (Open-Meteo)
- 🗓️ Daily Brief card, 🎙️ voice search, 🎲 Surprise Me roulette, 📴 offline-first PWA
- 💎N🎱 **Muse widget** (bottom-right) — 22 pocket tools + a straight line to chat with Muse
- ✨ 8 animations, 10 effects, 📲 always-visible install button

Single-file HTML + manifest + service worker. No build step, no dependencies.
